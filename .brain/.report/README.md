# Phase completion reports

Fill the matching report after all tests at the end of each phase. Keep reports in this folder and parallel to `.plan/PHASE-XX.md`. Do not record PASS without evidence. A failed test is useful evidence: record it, fix it, rerun, and update the same report with attempt history.

Each report is named `PHASE-XX-REPORT.md`. These blank files are templates; no project phase has been run or passed yet.
