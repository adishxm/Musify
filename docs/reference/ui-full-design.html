Iridescent ring
One light effect, once per screen

A Brush.sweepGradient over the chip, plus two larger translucent rings faking bloom. Modifier.blur needs API 31 and Musify supports 26 — the stack is visually identical on OLED and costs two draw calls.

Why it stays monochrome
A reflection, not a brand colour

The ring behaves like light hitting metal, so it reads as hardware rather than decoration. It appears exactly once per screen, so it never competes with the security-semantic colours.

Plate architecture
Two layers, one hairline

The pill sits on a slightly larger plate with a 1px iridescent hairline masked to the border. That is the entire "AI Mode" treatment — a second surface, not a shadow.

Editorial layer
Machine facts look machine-ish

Monospace, uppercase, tracked out, for timestamps, counts and states. Numerals use tabular figures so they never jitter while counting. Dot fields and tick rules fill negative space with intent.
