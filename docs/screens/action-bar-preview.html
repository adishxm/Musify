Why it's better here
14 actions, all visible at once

The old overflow buried 14 rows in a scrolling dropdown. The grid shows each one as a labelled, thumb-sized target — no scrolling, no guessing from an icon alone.

Emphasis without colour
One white object

The expand control is the only pure-white element on screen, so it reads as the primary affordance with no brand hue. Tiles stay neutral; glyphs carry meaning.

Motion
260ms, slide + scale

The panel rises and scales in on the house curve. The bar fades out beneath it, so the pill visually folds into the panel. The + rotates 45° into an × — one glyph, two states.

Target sizes
48dp tiles · 42dp pill items

Both clear the 48dp minimum touch target once padding is counted. Labels run to two lines so "Data & privacy" never truncates.
